- Restaurants need a simple and reliable donation workflow.

- Food donation listings

### 🎯 Abstract

This research explores the use of a **Reinforcement Learning–Guided Genetic Algorithm (RL-GA)** for optimizing firewall rule ordering and minimizing policy conflicts. The work compares RL-GA against SMT-based optimization approaches, evaluating performance using IPv6 firewall datasets while focusing on optimization quality, scalability, and execution efficiency.
